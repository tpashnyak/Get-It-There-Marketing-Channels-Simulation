# Get It There: Chapter 12 Interactive Lesson

Managing Marketing Channels and Supply Chains (Kerin & Hartley, *Marketing: The Core*, 2024 Release).

## Publish on GitHub Pages
1. Upload `index.html` and the whole `videos/` folder to the repository root, keeping the folder name.
2. Go to Settings → Pages → Deploy from branch → `main` / root.
